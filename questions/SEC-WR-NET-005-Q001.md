# SEC-WR-NET-005-Q001

- 영역: 정보보안기사 필기 · 네트워크 보안
- 세부 유형: HTTPS와 TLS 보호 범위
- 난이도: 기초 응용
- 권장 풀이시간: 100초
- 출처 유형: 독창적 비공식 연습문제
- 검수: RFC 9110·RFC 8446 대조

직원이 HTTPS로 내부 업무 사이트에 접속한다. TLS 연결이 정상적으로 성립해 통신 경로의 기밀성과 무결성이 보호되더라도, 웹 애플리케이션의 접근권한 검사가 잘못 구현되어 있다면 다른 직원의 자료가 노출될 수 있다.

가장 적절한 설명은?

1. HTTPS 연결이 성립했으므로 애플리케이션 접근권한도 올바르다고 보장된다.
2. TLS는 전송 중 통신을 보호하지만, 애플리케이션의 권한 검사 취약점까지 자동으로 해결하지는 않는다.
3. HTTPS는 데이터 무결성만 제공하고 통신 내용의 기밀성은 제공하지 않는다.
4. 서버 인증서가 유효하면 해당 서버의 모든 기능이 안전하다는 뜻이다.
