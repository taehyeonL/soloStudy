# CS-NET-011-Q001

- 영역: 전산 전공 · 컴퓨터 네트워크
- 세부 유형: TCP와 UDP의 전달 특성
- 난이도: 기초
- 권장 풀이시간: 90초
- 출처 유형: 독창적 비공식 연습문제
- 검수: IETF RFC 9293·RFC 768 대조

TCP는 응용 간 연결과 바이트 스트림 전송을 제공하며, UDP는 최소한의 프로토콜 메커니즘을 사용하는 데이터그램 방식이다.

TCP와 UDP의 차이에 대한 설명으로 맞는 것은?

1. TCP는 순서 있는 신뢰성 스트림 전달 기능을 제공하고, UDP는 전달·중복 방지를 보장하지 않는다.
2. UDP는 항상 TCP보다 안전한 암호화를 제공한다.
3. TCP와 UDP는 모두 전달 순서와 재전송을 보장하지 않는다.
4. UDP는 연결을 설정해야만 데이터를 보낼 수 있다.
