# SEC-WR-SYS-001-Q009

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 계정 생애주기·권한 회수
- 난이도: 기초 응용
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

직원이 부서를 옮겨 더 이상 급여 업무를 맡지 않게 되었다. 이전 업무 때 부여받은 급여 시스템 수정 권한은 계속 남아 있다.

**가장 적절한 보안 조치는 무엇인가?**

1. 사용 편의를 위해 기존 권한을 계속 유지한다
2. 현재 직무에 필요하지 않은 급여 수정 권한을 회수하고 변경 이력을 남긴다
3. 다른 직원과 계정을 공유하게 한다
4. 계정 비밀번호만 변경한다
