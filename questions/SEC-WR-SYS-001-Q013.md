# SEC-WR-SYS-001-Q013

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 보안 패치 관리
- 난이도: 기초 응용
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

서버 운영팀이 공개된 보안 취약점에 대한 제조사 패치를 확인했다. 이 서버는 업무 핵심 시스템이라 바로 적용하면 서비스 영향이 있을 수 있다.

**가장 적절한 대응은 무엇인가?**

1. 서비스 영향이 걱정되므로 패치를 영구히 미룬다
2. 패치 출처와 적용 영향을 확인하고, 승인된 변경·검증 절차에 따라 적시에 적용한다
3. 패치 파일을 출처 확인 없이 즉시 운영 서버에 설치한다
4. 취약점과 패치 정보를 운영 기록에서 삭제한다
