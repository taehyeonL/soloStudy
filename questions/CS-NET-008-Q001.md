# CS-NET-008-Q001

- 영역: 전산 전공 · 컴퓨터 네트워크
- 세부 유형: IPv4 프리픽스와 네트워크 부분
- 난이도: 기초
- 권장 풀이시간: 90초
- 출처 유형: 독창적 비공식 연습문제
- 검수: IETF RFC 4632 CIDR 프리픽스 표기 대조

CIDR 표기에서 IPv4 주소 뒤의 슬래시 숫자는 네트워크 프리픽스의 비트 길이를 나타낸다.

IPv4 주소 192.168.10.25/24에서 /24가 의미하는 것은?

1. 앞의 24비트가 네트워크 프리픽스 부분이다.
2. 주소 전체가 24비트로 구성된다.
3. 뒤의 24비트가 호스트 부분이다.
4. 네트워크 프리픽스가 24개라는 뜻이다.

번호와 이유를 알려주세요.
