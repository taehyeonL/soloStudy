# SEC-WR-SYS-001-Q008

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 최소권한 원칙 적용
- 난이도: 기초 응용
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

한 배치 작업 계정은 매일 보고서 파일을 읽기만 하면 된다. 그런데 해당 계정에 서버 관리자 권한이 부여되어 있다.

**가장 적절한 보안 개선은 무엇인가?**

1. 관리자 권한을 유지하고 비밀번호만 더 길게 설정한다
2. 업무에 필요한 보고서 읽기 권한만 부여하고 관리자 권한을 제거한다
3. 모든 직원에게 같은 관리자 계정을 제공한다
4. 계정 활동 로그를 남기지 않는다
