# SEC-WR-SYS-001-Q010

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 계정 책임추적성
- 난이도: 기초
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

여러 직원이 하나의 공용 관리자 계정을 사용한다. 사고가 발생했을 때 특정 작업을 누가 수행했는지 로그만으로 구분하기 어렵다.

**책임추적성을 높이는 가장 적절한 개선은 무엇인가?**

1. 공용 계정을 유지하고 비밀번호를 정기적으로 바꾼다
2. 사용자별 계정을 사용하고 주요 작업의 수행자·시각·결과를 기록한다
3. 작업자 구분을 막기 위해 로그를 삭제한다
4. 모든 사용자에게 동일한 계정 이름을 부여한다
