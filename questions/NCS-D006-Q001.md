# NCS-D006-Q001

- 영역: NCS 의사소통
- 세부 유형: 공지문 목적·행동·기한
- 난이도: 기초
- 권장 풀이시간: 90초
- 출처 유형: 독창적 비공식 연습문제
- 검수: 지문 조건과 선택지 수동 대조

다음은 사내 교육 안내문이다.

“교육 참석자는 교육 종료 후 2시간 이내에 만족도 설문을 제출해야 합니다. 설문은 교육 포털에서 작성하며, 종이 설문은 받지 않습니다.”

안내에 맞는 행동은?

1. 교육 시작 후 2시간 이내에 종이 설문을 제출한다.
2. 교육 종료 후 2시간 이내에 포털에서 설문을 작성한다.
3. 교육 당일 자정까지 이메일로 설문을 보낸다.
4. 설문 제출은 선택이며 종이와 포털 중 선택할 수 있다.

번호와 이유를 알려주세요.
