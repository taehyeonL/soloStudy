IP 주소와 TCP 포트는 서로 다른 통신 기능에 쓰인다.

두 기능을 계층과 연결한 설명으로 맞는 것은?

1. IP 주소를 바탕으로 목적지 네트워크를 찾는 기능은 인터넷 계층, TCP 포트로 프로세스를 구분하는 기능은 전송 계층이다.
2. IP 주소를 바탕으로 목적지 네트워크를 찾는 기능은 전송 계층, TCP 포트로 프로세스를 구분하는 기능은 인터넷 계층이다.
3. 두 기능 모두 링크 계층에서 처리한다.
4. 두 기능 모두 응용 계층에서 처리한다.
