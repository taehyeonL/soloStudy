# SEC-WR-NET-002-Q002

- 영역: 정보보안기사 필기 · 네트워크 기초 보완
- 세부 유형: IP와 TCP 계층 적용
- 난이도: 기초 보완
- 권장 풀이시간: 75초
- 출처 유형: 독창적 비공식 보완 연습문제
- 검수: IETF RFC 1122 계층 분류 수동 대조

방화벽 로그에 목적지 IP 주소와 TCP 목적지 포트 443이 기록되어 있다. 이때 IP 주소 기반 전달과 TCP 포트 기반 서비스 구분에 대한 설명으로 맞는 것은?

1. IP 주소는 인터넷 계층, TCP 포트는 전송 계층의 정보다.
2. IP 주소와 TCP 포트는 모두 인터넷 계층의 정보다.
3. IP 주소는 전송 계층, TCP 포트는 링크 계층의 정보다.
4. IP 주소와 TCP 포트는 모두 응용 계층의 정보다.
