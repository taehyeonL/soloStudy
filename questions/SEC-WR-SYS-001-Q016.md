# SEC-WR-SYS-001-Q016

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 침투경로·위장·전파방식 구분
- 난이도: 응용(실전형)
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

직원을 겨냥한 기만성 이메일이 ‘업무 문서 뷰어 업데이트’를 설치하도록 유도했다. 설치 파일은 정상 업데이트처럼 보이지만 숨겨진 백도어 기능을 수행했다. 실행 뒤에는 취약한 SMB 호스트를 찾아 자기 복제본을 전파했다.

**사건을 설명한 문장으로 가장 정확한 것은?**

1. 이메일은 웜이고, 정상 업데이트 위장은 피싱 페이로드이며, SMB 복제는 트로이목마의 정의다.
2. 이메일은 전달·유도 경로인 피싱이고, 숨겨진 악성 기능은 트로이목마 특성, SMB 자기복제 확산은 웜의 전파 특성으로 각각 설명할 수 있다.
3. 사용자가 최초 파일을 실행했으므로 이후의 네트워크 자기복제도 반드시 바이러스이며 웜일 수 없다.
4. 백도어 기능과 SMB 전파가 있으므로 파일 암호화가 없어도 랜섬웨어로 분류해야 한다.
