# SEC-WR-SYS-001-Q007

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: MAC 접근통제 식별
- 난이도: 기초 보완
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

기관의 보안관리자가 정한 보안등급과 중앙 접근정책에 따라 문서 접근이 자동 제한된다. 문서 작성자나 소유자는 다른 사용자에게 임의로 권한을 넘길 수 없다.

**이 접근통제 모델은 무엇인가?**

1. DAC(임의적 접근통제)
2. MAC(강제적 접근통제)
3. RBAC(역할 기반 접근통제)
4. 다중요소 인증
