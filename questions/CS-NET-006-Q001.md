# CS-NET-006-Q001

- 영역: 전산 전공 · 컴퓨터 네트워크
- 난이도: 기초 응용
- 권장 풀이시간: 120초
- 출처: 독창적 비공식 연습문제
- 검수: RFC 대조와 수신 구간 코드 검증

TCP 연결이 설정되어 있고 서버는 처음에 데이터 번호 2000을 기대했다. 서버는 2000~2099를 받았고, 2200~2299도 먼저 받아 버퍼에 저장했다. 이후 누락됐던 2100~2199가 도착했다. 이전 누락은 없고 SYN·FIN은 없으며 수신 창은 충분하다.

누락됐던 데이터까지 받은 뒤 서버의 누적 ACK 번호는?

1. 2100
2. 2200
3. 2300
4. 2301

번호와 이유를 알려주세요.
