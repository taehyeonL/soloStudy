# NCS-D001-Q001

- 영역: 의사소통 (기존·개편 공통)
- 세부 유형: 공지문 정보 확인
- 난이도: 기초
- 권장 풀이시간: 90초 (실제 시간은 별도)
- 출처 유형: 독창적 창작, 기출 아님
- 검수 상태: 통과 (조건 모델 검사 및 수동 지문 대조)

다음 공지에 따라 정상적으로 신청한 경우를 고르세요. 신청 내용 등 다른 요건은 모두 충족했다고 가정합니다.

> 교육 신청은 수요일 09시부터 16시까지 온라인 신청서로만 받습니다. 시작 시각과 마감 시각의 신청도 접수합니다. 방문 신청은 받지 않습니다. 정해진 시간에 온라인 신청서를 제출하면 별도 절차 없이 신청이 완료됩니다.

1. 수요일 17시에 온라인 신청서를 제출했다.
2. 목요일 15시에 온라인 신청서를 제출했다.
3. 수요일 15시에 온라인 신청서를 제출했다.
4. 수요일 15시에 방문하여 신청했다.

선택 번호와 고른 이유를 답하세요. 직접 잰 시간이 있으면 함께 알려주세요. 시간은 생략해도 됩니다.
