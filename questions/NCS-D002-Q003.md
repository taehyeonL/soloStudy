# NCS-D002-Q003

- 영역: NCS · 의사소통
- 유형: 두 문장의 조건을 보존해 한 문장으로 요약
- 난이도: 기초 응용
- 권장시간: 75초
- 출처: 독창적 연습문제, 실제 기출 아님
- 검수: 지문 정보와 선택지 역할 수동 대조

전산팀은 월간 점검표를 매월 마지막 근무일 17시까지 공용 저장소에 올린다. 긴급 장애 기록은 복구 후 1시간 이내 팀장에게 전화로 보고한다.

두 문장의 조건을 모두 정확히 요약한 것은?

1. 월간 점검표는 매월 마지막 근무일 17시까지 공용 저장소에 올리고, 긴급 장애 기록은 복구 후 1시간 안에 팀장에게 전화로 보고한다.
2. 월간 점검표는 복구 후 1시간 안에 팀장에게 전화로 보고하고, 긴급 장애 기록은 매월 마지막 근무일 17시까지 공용 저장소에 올린다.
3. 월간 점검표와 긴급 장애 기록을 모두 매월 마지막 근무일 17시까지 공용 저장소에 올린다.
4. 월간 점검표는 매주 금요일까지 팀장에게 전화로 보고하고, 긴급 장애 기록은 복구 즉시 공용 저장소에 올린다.
