# SEC-WR-NET-004-Q001

- 영역: 정보보안기사 필기 · 네트워크 보안 기초
- 세부 유형: UDP 특성 이해
- 난이도: 기초
- 권장 풀이시간: 90초
- 출처 유형: 독창적 비공식 연습문제
- 검수: IETF RFC 768 대조

RFC768은 UDP를 데이터그램 방식의 전송 프로토콜로 설명하고, 전달과 중복 방지가 보장되지 않는다고 명시한다.

UDP에 대한 설명으로 가장 적절한 것은?

1. 데이터그램 방식이며 전달과 중복 방지가 보장되지 않는다.
2. 연결을 설정하고 모든 데이터의 순서 전달을 보장한다.
3. 자체적으로 전송 데이터를 암호화한다.
4. 포트 번호를 사용하지 않는다.
