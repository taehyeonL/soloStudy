# CS-NET-002-Q003

- 영역: 전산 전공 / 네트워크
- 공통 개념: NET-TCPIP
- 난이도: 기초 보완
- 권장 풀이시간: 60초
- 출처: 독창적 연습문제, 기출 아님
- 검수: RFC 대조·구조 검사 통과

클라이언트가 먼저 SYN을 보내고, 서버가 SYN+ACK로 응답한 뒤, 클라이언트가 마지막 ACK를 보내는 기본 TCP 연결 설정 상황이다.

서버가 보낸 SYN을 확인하는 메시지는 무엇인가?

1. 클라이언트가 처음 보낸 SYN
2. 서버가 보낸 SYN+ACK
3. 클라이언트가 마지막에 보낸 ACK
4. TCP에는 서버 SYN을 확인하는 메시지가 없다

번호와 이유를 답하세요.
