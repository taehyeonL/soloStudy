# SEC-WR-SYS-001-Q005

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 접근통제 모델 식별
- 난이도: 기초
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

한 기관 시스템은 사용자의 부서와 직무 역할에 따라 미리 정한 권한을 부여한다. 예를 들어 인사팀은 인사기록을 읽고 수정할 수 있고, 일반 직원은 자신의 정보만 조회할 수 있다.

**이 사례에 가장 잘 맞는 접근통제 모델은 무엇인가?**

1. DAC(임의적 접근통제)
2. MAC(강제적 접근통제)
3. RBAC(역할 기반 접근통제)
4. 다중요소 인증
