# SEC-WR-ACCESS-001-Q001

- 영역: 정보보안기사 필기·접근통제/개인정보 보호
- 세부 유형: 복합 보안조건 적용
- 난이도: 기초 응용
- 출처 유형: 독창 연습문제
- 검수 상태: 검수 완료

기관 규정상 개인정보를 외부로 전송하려면 “전송 파일 암호화”와 “관리자 사전 승인”을 모두 충족해야 한다. 규정을 충족한 전송은?

1. 파일을 암호화했고 관리자 사전 승인을 받았다.
2. 파일을 암호화했지만 사전 승인은 받지 않았다.
3. 파일은 암호화하지 않았지만 사전 승인은 받았다.
4. 암호화와 사전 승인을 모두 하지 않았다.

- 권장 풀이시간: 60초
