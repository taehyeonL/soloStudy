# SEC-WR-SYS-001-Q015

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 악성코드 전파 방식 식별
- 난이도: 기초 응용(실전형)
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

한 직원이 이메일 첨부파일을 실행한 뒤 PC가 감염되었다. 이후 악성 프로그램은 별도 사용자 실행 없이 취약한 SMB 서비스를 이용해 내부 여러 PC로 스스로 복제·전파됐다. 파일 암호화와 금전 요구는 관찰되지 않았다.

**이 사례에서 내부 확산을 가장 잘 설명하는 악성코드 유형은 무엇인가?**

1. 바이러스 — 다른 파일에 붙어 감염 파일의 실행에 의존하는 유형
2. 웜 — 독립적으로 네트워크를 통해 자신을 복제·전파하는 유형
3. 트로이목마 — 정상 소프트웨어로 위장하는 유형
4. 랜섬웨어 — 데이터를 잠그거나 암호화해 대가를 요구하는 유형
