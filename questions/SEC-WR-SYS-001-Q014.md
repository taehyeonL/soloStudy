# SEC-WR-SYS-001-Q014

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 취약점·패치 우선순위 및 변경관리
- 난이도: 기초 응용(실전형)
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

외부에서 접속 가능한 업무 서버가 공급업체가 공지한 원격 코드 실행 취약점의 영향을 받는 버전을 사용하고 있다. 공급업체 패치가 배포됐고, 운영팀에는 격리된 사전 검증 환경과 긴급 변경 절차가 있다.

**가장 적절한 대응은 무엇인가?**

1. 긴급 변경 절차를 사용하되 사전 검증은 생략하고 전체 서버에 동시에 적용한 뒤 장애가 발생하면 복구한다.
2. 영향 버전과 패키지 진위를 확인하고, 가능한 빠른 사전 검증·백업·승인된 긴급 변경을 거쳐 우선 적용한 뒤 정상 동작과 취약점 해소를 확인한다.
3. 다음 정기 월간 작업까지 적용을 미루고 기존 접근 상태를 유지하면서 로그만 확인한다.
4. 업무 영향 평가 없이 서버를 영구 종료하고, 자산·서비스 담당자에게 알리지 않는다.
