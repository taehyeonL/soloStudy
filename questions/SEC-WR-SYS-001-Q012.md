# SEC-WR-SYS-001-Q012

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 운영체제 보안 강화
- 난이도: 기초 응용
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

공공기관 내부 서버를 새로 설치했다. 해당 업무에 쓰지 않는 네트워크 서비스가 기본 설정으로 실행 중이며, 외부에서 접속 가능한 상태다.

**가장 적절한 보안 조치는 무엇인가?**

1. 사용하지 않는 서비스를 비활성화하고 필요한 서비스만 허용한다
2. 모든 서비스와 포트를 열어 향후 사용에 대비한다
3. 서버 관리자 계정 하나를 전 직원이 공유한다
4. 보안 업데이트를 중단해 설정 변화를 막는다
