# SEC-WR-SYS-001-Q011

- 영역: 정보보안기사 필기 · 시스템 보안
- 유형: 로그 무결성 보호
- 난이도: 기초 응용
- 출처 유형: 독창적 비공식 연습문제; 공식 기출 아님
- 검수 상태: passed

관리자 계정이 침해된 뒤 공격자가 자신의 흔적을 숨기기 위해 시스템 로그를 삭제했다.

**로그 변조·삭제 위험을 줄이는 데 가장 직접적으로 도움이 되는 조치는 무엇인가?**

1. 로그를 해당 시스템 안에만 저장하고 관리자 모두에게 삭제 권한을 준다
2. 로그를 별도 보호 저장소로 전달하고 로그 접근·변경 권한을 제한한다
3. 로그 기록 기능을 끈다
4. 모든 계정이 로그를 수정할 수 있도록 허용한다
