# CS-NET-012-Q001

- 영역: 전산 전공 · 컴퓨터 네트워크
- 세부 유형: DNS·HTTP 장애 계층 구분
- 난이도: 기초 응용
- 권장 풀이시간: 100초
- 출처 유형: 독창적 비공식 연습문제
- 검수: RFC 1034·RFC 9110 대조

사용자가 웹 서비스 주소를 입력하면 운영체제는 먼저 해당 도메인의 IP 주소를 DNS로 조회한다. IP 주소를 얻은 뒤 웹 클라이언트는 서버에 HTTP 요청을 보내고 응답 상태 코드를 받는다.

DNS 조회는 성공하여 서버 IP를 얻었지만 HTTP 응답으로 404가 돌아왔다. 가장 적절한 해석은?

1. DNS가 도메인을 IP 주소로 해석했으며, HTTP 요청 대상 리소스를 찾지 못했음을 나타낼 수 있다.
2. DNS가 HTTP 요청을 거부했으므로 클라이언트가 서버 IP 주소를 얻지 못했다.
3. 404는 서버가 요청을 처리하지 못했음을 뜻하는 5xx 서버 오류다.
4. DNS가 성공했으므로 해당 웹 서버의 모든 페이지가 정상임이 확인되었다.
