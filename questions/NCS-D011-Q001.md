# NCS-D011-Q001

- 영역: NCS 의사소통
- 세부 유형: 근거 범위 안에서 추론
- 난이도: 기초
- 권장 풀이시간: 100초
- 출처 유형: 독창적 비공식 연습문제
- 검수: 지문 근거가 뒷받침하는 범위 수동 대조

다음은 새 전자결재 시스템 사용 설문 결과다.

“설문에 응답한 직원 20명 중 15명은 결재 진행 상태를 확인하기 쉬워졌다고 답했다. 나머지 5명은 이전 시스템을 사용하지 않아 비교하기 어렵다고 답했다.”

지문으로부터 가장 타당하게 추론할 수 있는 것은?

1. 설문 응답자 다수는 결재 진행 상태를 확인하기 쉬워졌다고 평가했다.
2. 모든 직원은 새 시스템이 결재 시간을 줄였다고 평가했다.
3. 이전 시스템을 쓰던 모든 직원은 새 시스템을 더 선호한다.
4. 새 시스템은 모든 기관에서 결재 오류를 없앤다.

번호와 근거를 알려주세요.
