# CS-NET-001-Q002

- 영역: 전산 전공 / 네트워크
- 개념: NET-TCPIP
- 난이도: 기초 응용
- 권장 시간: 90초
- 출처: 독창적 연습문제, 공식 기출 아님
- 검수: RFC 대조 수동 검수·구조 검사 통과

연습 상황: 같은 IP 주소 10.0.0.10을 사용하는 서버에서 서비스 A는 TCP 8080번 포트, 서비스 B는 TCP 9090번 포트에서 각각 연결을 기다리고 있다.

이 상황에 대한 설명으로 옳은 것은?

1. 두 서비스의 IP 주소가 같으므로 클라이언트는 접속 대상을 구분할 수 없다.
2. 클라이언트는 목적지 포트 번호를 달리하여 서비스 A와 B에 접속할 수 있다.
3. TCP를 사용하므로 두 서비스의 통신 내용은 TCP 자체에 의해 자동 암호화된다.
4. 8080과 9090은 두 서비스가 사용하는 서로 다른 목적지 IP 주소이다.
