# NCS-D009-Q001

- 영역: NCS 의사소통
- 세부 유형: 주장과 근거
- 난이도: 기초
- 권장 풀이시간: 100초
- 출처 유형: 독창적 비공식 연습문제
- 검수: 문단 주장과 자료 근거의 범위를 수동 대조

다음은 민원 처리 현황에 관한 글이다.

“지난 분기 민원 처리에 걸린 평균 기간은 4일이었다. 업무 절차를 정비한 이번 분기에는 평균 처리 기간이 3일로 줄었다. 담당 부서는 처리 절차가 개선되었다고 평가했다.”

‘이번 분기에 평균 처리 기간이 줄었다’는 내용을 직접 뒷받침하는 근거는?

1. 지난 분기 평균 4일, 이번 분기 평균 3일이라는 기록
2. 담당 부서는 절차가 개선되었다고 평가했다는 내용
3. 새 업무 절차가 기간 단축의 유일한 원인이라는 판단
4. 모든 민원이 정확히 하루씩 더 빨리 처리되었다는 내용
