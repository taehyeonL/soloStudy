# Day 1 — NCS와 공지문 독해 첫걸음

예상 전체 학습: 60~75분. 실제 소요시간은 미확인. 도래 복습: 없음.

목표: NCS가 무엇인지 자기 말로 설명하고, 업무 문서에서 주체·행동·시간·방법을 찾아 근거로 선택지를 판단한다.

## 블록 1: 개념과 풀이 시범 (예상 15~20분)

NCS는 국가직무능력표준의 약자다. 현장에서 일을 수행할 때 필요한 지식·기술·태도를 정리한 기준이다. 공공기관 채용에서 ‘NCS 시험’이라고 할 때는 흔히 업무에 공통으로 필요한 독해·계산·문제해결 등의 평가를 가리킨다. 전산 전공시험은 별도로 출제될 수 있으므로 공고에서 구분한다.

개발 업무에 연결하면, 요구사항 문서를 정확히 읽는 일은 의사소통, 사용량과 비용을 계산하는 일은 수리, 여러 제약 안에서 일정을 정하는 일은 문제해결과 연결된다. 실제 업무 경험은 예시를 이해하는 데 도움이 되지만 시험 풀이법은 기초부터 익힌다.

기존 직업기초능력은 10영역, 개편 직업공통능력은 7영역이다. 기존의 자원관리·조직이해 같은 명칭과 개편의 자기관리·디지털 같은 명칭을 구분한다. 상세 목록은 curriculum.md, 근거는 sources.md. 오늘은 두 체계의 공통 핵심인 의사소통부터 시작한다. 기관별 실제 공고가 시험 범위를 정한다.

‘지문’은 문제에서 읽으라고 제시한 글, ‘선택지’는 고를 수 있는 답 후보, ‘근거’는 그 답이 맞는지 확인할 수 있는 글 속 정보다. ‘독해’는 글의 의미와 관계를 정확하게 읽는 것이다. 아는 업무 관행을 덧붙이기보다 문제에 제시된 정보를 기준으로 판단한다.

기본 순서: 무엇을 묻는지 확인 → 글에서 주체·행동·시간·방법 표시 → 선택지를 조건과 대조 → 고른 이유를 한 문장으로 설명.

### 풀이 시범 NCS-D001-E001

독창적 연습 예제. 검수 통과. 권장 60초이며 강사가 설명하는 시범은 풀이 통계에서 제외한다.

> 개발팀은 회의 자료를 금요일 14시까지 공동 폴더에 올려야 한다. 메일 제출은 받지 않는다. 자료 업로드만으로 제출이 완료되며 별도 승인은 필요 없다.

질문: 공지에 맞게 자료를 제출한 경우는?

1. 금요일 13시에 메일로 보냈다.
2. 금요일 15시에 공동 폴더에 올렸다.
3. 금요일 13시에 공동 폴더에 올렸다.
4. 금요일 13시에 메신저로 보냈다.

시범 정답은 3번. 정석 풀이: 대상은 개발팀 회의 자료, 마감은 금요일 14시까지, 방법은 공동 폴더다. 3번만 마감과 방법을 모두 충족한다. 1번은 메일, 2번은 마감 후, 4번은 메신저여서 맞지 않는다. 빠른 풀이는 ‘14시까지/공동 폴더’ 두 조건을 옆에 적고 대조하는 것이다. 실무에서 메일을 자주 사용한다는 경험이 있어도 이 지문의 조건을 바꿀 수는 없다.

강사 점검: 지문·선택지 원문은 questions/_instructor/NCS-D001-E001.json에 기록한다. 규칙의 코드 모델과 4개 선택지를 대조하여 한 선택지만 조건을 만족하는지 확인했다. 자연어와 모델의 대응은 수동 검수했다.

## 블록 2: 기초 문제 (예상 15~20분)

questions/NCS-D001-Q001.md 한 문제만 제시하고 답변을 기다린다. 답·이유를 받은 뒤 판정, 정석 풀이, 빠른 풀이, 함정, 원인, 관련 개념 순으로 설명한다. 정답은 이 강의 파일에 넣지 않는다. 시간은 사용자가 보고한 경우만 기록한다.

틀렸거나 풀이가 불안정하면 원인을 확인하고 오답노트·복습에 등록한다. 이해가 어려우면 더 단순한 문서 예시로 재설명한다.

## 블록 3: 응용과 정리 (예상 15~20분)

Q001 피드백 후에만 questions/NCS-D001-Q002.md를 제시한다. 조건 두 개와 예외를 구분하는 응용이다. 답변 전에는 파일 전체나 정답 데이터를 채팅에 공개하지 않는다.

마무리: 학습자가 ‘NCS의 뜻’과 ‘문서를 읽을 때 확인할 항목’을 자기 말로 요약하도록 돕는다. `오늘 공부 끝`을 받으면 실제 학습 결과를 저장하고 달성 여부를 평가한다. Day 1이 미완료이면 다음 세션에서 이어간다.
