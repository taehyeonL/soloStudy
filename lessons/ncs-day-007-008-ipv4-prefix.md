# 통합 패키지: NCS Day 7–8 + IPv4 주소·프리픽스 기초

기준일 2026-10-27. 예상 80–95분(실측 아님). 복습은 오늘 도래 0건, 다음 2026-10-28에 5건 예정이다.

## 이론 목차

### NCS Day 7 — 1주차 통합 미니평가
1. 문장 조건과 예외를 분리하기
   1.1 기본 의무와 조건부 예외 표시
   1.2 선택지에 추가되거나 누락된 조건 확인
2. 문서 정보 요약
   2.1 행동·대상·기한·제출처 대조
   2.2 지문 근거를 짧게 설명

시범: 안내문에서 “모든 부서”는 적용 대상을, “다만 변경 시”는 예외 조건을 나타낸다. 선택지가 제출기한을 바꾸거나 지문에 없는 제출방법을 더했는지 확인한다.

### NCS Day 8 — 문단의 중심 내용
1. 중심 내용과 세부 정보
   1.1 문단의 중심 문장은 전체 주제를 제시
   1.2 사례·수치·절차는 중심 내용을 뒷받침
2. 중심 내용 찾는 순서
   2.1 반복되는 대상과 핵심 변화 표시
   2.2 “이 문단이 궁극적으로 말하는 것”을 한 문장으로 정리
   2.3 세부 예시만 말하는 선택지 제거

시범: 여러 문장이 오류 예방 방법을 설명하고 마지막에 “따라서 입력 후 검증 절차가 필요하다”고 정리한다면, 중심은 특정 버튼을 누르는 절차가 아니라 입력 검증의 필요성이다.

### 전산 전공 + 정보보안기사 필기 공통 — IPv4 네트워크·호스트 구분과 프리픽스
1. IPv4 주소
   1.1 32비트 주소를 점으로 구분한 4개 10진수로 표현
   1.2 주소는 목적지 인터페이스 식별에 쓰임
2. 프리픽스 표기
   2.1 `/24`는 앞 24비트가 네트워크 부분이라는 뜻
   2.2 나머지 8비트는 해당 프리픽스 안의 주소 부분
   2.3 네트워크 주소는 주소와 서브넷 마스크를 AND한 결과
3. 사설 IPv4 범위(보안기사 적용)
   3.1 10.0.0.0/8
   3.2 172.16.0.0/12
   3.3 192.168.0.0/16
   3.4 사설 주소라는 사실만으로 접근통제가 보장되지는 않음

시범: `192.168.10.25/24`에서 프리픽스 `/24`는 앞의 24비트가 네트워크 부분임을 뜻한다. 사설 주소 범위는 IETF RFC 1918에 명시돼 있다. CIDR 프리픽스 표기는 RFC 4632를 참고한다.

## 기본 문제와 보완

- NCS Day7 1문제 + Day8 1문제
- 전산 전공 IPv4/프리픽스 1문제
- 정보보안기사 필기 사설 주소 적용 1문제
- 정보보안기사 실기 0문제(실기 집중 구간 전), 평일 TOEIC 0문제(주말 RC 전용)
- 총 4문제. 오답·불안정 개념이 있을 때만 해당 개념별 유도형 1 + 독립형 1 추가

출처: IETF RFC 1918 https://www.rfc-editor.org/rfc/rfc1918.html, RFC 4632 https://www.rfc-editor.org/rfc/rfc4632.html (확인 2026-10-27). RFC는 네트워크 표준 원문이며, 문제는 독창적 비공식 연습문제다.
