# 통합 패키지: NCS Day 9–10 + 서브넷 마스크·네트워크 주소

기준일 2026-10-27. 예상 80–95분(실측 아님). 오늘 도래 복습 0건, 다음 10월28일 3건.

## 이론 목차

### NCS Day 9 — 주장과 근거
1. 주장
   1.1 글쓴이가 전달하거나 판단하는 핵심 문장
2. 근거
   2.1 수치·사실·조사 등 주장을 뒷받침하는 자료
   2.2 근거가 실제로 주장과 같은 대상을 설명하는지 확인
3. 연결 점검
   3.1 근거가 주장보다 넓게 일반화하지 않는가
   3.2 수치 변화와 원인 주장을 구분

시범: 처리시간이 4일에서 3일로 바뀌었다는 기록은 “처리기간이 짧아졌다”는 주장 근거다. 하지만 별도 비교자료 없이 “새 시스템 때문에 짧아졌다”고 원인까지 단정할 수는 없다.

### NCS Day 10 — 내용 일치·불일치
1. 지문 조건 분해
   1.1 대상·행동·기한·예외 표시
2. 선택지 대조
   2.1 선택지의 핵심 표현마다 지문 근거 확인
   2.2 기한·대상·정도 표현의 작은 변경을 탐지
3. 판단
   3.1 지문과 같은 내용 / 반대 내용 / 언급 없음 구분

시범: “다음 근무일까지 제출”을 “오늘 제출”로 바꾸면 기한이 달라진 불일치다. “제출 담당자는 만족했다”는 지문에 없는 내용이면 언급 없음이다.

### 전산 전공 + 정보보안기사 필기 공통 — 서브넷 마스크와 네트워크 주소
1. IPv4 32비트 구조 복습
   1.1 `/24`와 `255.255.255.0`의 대응
2. AND 연산
   2.1 주소의 비트와 마스크의 비트를 AND
   2.2 1 AND 1만 1, 나머지는 0
3. 네트워크 주소 계산
   3.1 IP 주소 AND 서브넷 마스크
   3.2 예: 192.168.10.77 AND 255.255.255.0 = 192.168.10.0
4. 보안 적용
   4.1 ACL/방화벽의 CIDR 대역 매칭
   4.2 허용 규칙이 네트워크 전체에 적용되는지 확인

CIDR 프리픽스 표기는 IETF RFC 4632에 설명되어 있다. 강의 예제의 네트워크 주소 계산은 /24 경계에서 마지막 옥텟을 0으로 만드는 기초 사례다.

## 문제 수 및 운영

- NCS Day9 주장·근거 1 + Day10 내용 일치 1
- 전산 전공 서브넷 계산 1
- 정보보안기사 필기 방화벽 CIDR 적용 1
- 보안기사 실기 0(집중 학습 구간 전), 평일 TOEIC 0(주말 RC 전용)
- 기본 합계4문제. 오답·불안정이 확인된 개념에만 유도형1 + 독립형1 보완
- 문제 ID: NCS-D009-Q001, NCS-D010-Q001, CS-NET-009-Q001, SEC-WR-NET-003-Q001
