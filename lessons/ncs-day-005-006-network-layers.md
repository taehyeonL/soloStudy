# 통합 패키지: NCS Day 5–6 + 네트워크 계층

기준일: 2026-10-27. 예상 75–90분이며 실측시간은 별도 기록한다. 기본 문제는 NCS 2, 전산 전공 1, 정보보안기사 필기 1. 보안기사 실기 0(이번 패키지는 공통 네트워크 기초와 필기 트랙을 다루며 실기 서술형 구간은 후속 학습 블록에 편성). 평일 TOEIC 0(주말 RC 진단 전용).

## 이론 목차

### NCS Day 5 — 조건·예외·한정 표현
1. 문장 범위 읽기
   1.1 반드시/모두: 강한 의무·전체 범위
   1.2 일부/가능: 범위가 제한되거나 허용됨
2. 조건과 예외
   2.1 “~인 경우”, “~하지 않으면”: 조건
   2.2 “다만”, “단”: 기본 규칙에서 빠지는 예외
3. 선택지 검증
   3.1 지문에 없는 의무를 추가하지 않기
   3.2 예외를 기본 규칙으로 확대하지 않기

**풀이 시범:** “모든 신청자는 신청서를 낸다. 다만, 재직증명서 발급이 어려우면 인사담당자 확인서로 대체할 수 있다.”에서 신청서 제출은 전체 의무다. 확인서는 조건이 맞을 때만 재직증명서를 대신한다. 확인서가 신청서까지 대체한다고 읽으면 범위를 바꾼 것이다.

### NCS Day 6 — 공지·메일·규정에서 행동 정보 찾기
1. 문서의 목적과 대상
   1.1 누가 읽는가
   1.2 무엇을 하도록 안내하는가
2. 실행 조건 추출
   2.1 제출물·제출처
   2.2 마감 시점·예외·필수 행동
3. 짧은 요약 검증
   3.1 요구 행동과 기한을 한 쌍으로 표시
   3.2 요약에 빠진 조건·추가된 조건 찾기

**풀이 시범:** 안내문을 읽을 때 “누가 / 무엇을 / 언제까지 / 어디로 / 어떤 예외로”를 표시한다. 예컨대 기한이 “교육 종료 후 2시간 이내”라면 이를 “당일 중”으로 뭉뚱그리지 않는다.

### 전산 전공 + 정보보안기사 필기 공통 — 네트워크 계층과 캡슐화
1. 계층화의 뜻
   1.1 복잡한 통신 기능을 역할별로 나눔
   1.2 각 계층은 아래 계층의 전송 기능을 이용
2. TCP/IP 인터넷 프로토콜 묶음
   2.1 링크 계층: 같은 링크에서 프레임 전달
   2.2 인터넷 계층: IP 주소 기반 전달
   2.3 전송 계층: TCP/UDP, 포트 및 프로세스 간 전달
   2.4 응용 계층: HTTP 등 응용 프로토콜
3. OSI 7계층과의 학습용 대응
   3.1 물리·데이터링크 ↔ 링크 기능
   3.2 네트워크 ↔ 인터넷(IP)
   3.3 전송 ↔ TCP/UDP
   3.4 세션·표현·응용 ↔ TCP/IP 응용 계층에 묶어 설명하는 경우가 흔함
4. 캡슐화
   4.1 응용 데이터에 TCP/UDP 헤더가 붙어 세그먼트/데이터그램 형성
   4.2 IP 헤더가 붙어 IP 패킷(데이터그램) 형성
   4.3 링크 헤더·트레일러가 붙어 프레임 형성
   4.4 수신 측은 각 계층 헤더를 처리하며 위 계층으로 전달

**풀이 시범:** TCP/IP 실제 프로토콜 구분에서 TCP는 전송 계층, IP는 인터넷 계층에 놓인다. OSI 7계층 대응은 학습용 모델이며, 표준 문서는 TCP/IP의 실제 계층 이름을 쓴다. IETF RFC 1122는 링크·IP·전송 계층을 별도로 다룬다: https://www.rfc-editor.org/rfc/rfc1122.html
