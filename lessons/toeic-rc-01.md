# TOEIC RC 기초01 — 주어와 동사

목표700~750점, 지원자격보조과목·주2시간 배분 유지. 첫블록예상15~20분, 오늘영어기초예산10분이면설명·기초한문제까지만하고나머지다음에이어간다. 실제소요시간미확인. LC평가가아닌독창적문법연습이며점수환산하지않는다.

주어는문장에서무엇에대해말하는지나타내는부분, 이번행동문장에서는누가행동하는지찾는다. 동사는행동이나상태를나타내며이번에는check/inspect같은행동동사를쓴다. 목적어는행동의대상이다. 명사는사람·사물등의이름, 동사는행동·상태를나타내는단어종류다. 품사는단어종류, 주어·목적어는문장안역할이다.

The manager checks the schedule. 주어the manager(그관리자), 동사checks(확인한다), 목적어the schedule(그일정). check확인하다, manager관리자, schedule일정.

현재시제는지금의습관·반복행동등에쓴다. 오늘은조동사없는일반동사긍정문만다룬다. I/you/we/they는check, he/she/it처럼3인칭단수는checks. 3인칭은말하는나와듣는너이외, 단수는한사람/한대상이다. 명사manager한명은he/she처럼, managers여러명은they처럼동사형태를고른다. I와you에도s를붙이는것으로일반화하지않는다. be동사와부정문·의문문은후속학습이다.

명사의s는보통복수표시(employee→employees), 이번현재일반동사의s는3인칭단수표시(check→checks). 둘을구분한다.

풀이시범TOEIC-RC-001-E001: The manager _____ the schedule every morning. 선택지check/checks/checking/to check. 정답checks. 주어manager한명이므로현재일반동사checks. checking과to check는이번문장서술어를단독완성하지못한다. 문장뜻은그관리자는매일아침일정을확인한다. 시범은성적에합산하지않는다.

기초문제TOEIC-RC-001-Q001은학생용파일로한문제만제시하고답변대기. 어휘employee직원/equipment장비/inspect점검하다/every morning매일아침. 정답은강사용JSON에만저장하며미응답집계하지않는다.
