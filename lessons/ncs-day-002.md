# NCS Day 2 전체 — 문장 쪼개기와 한 문장 요약

**영역: NCS · 의사소통**  
**예상 학습시간: 60~75분 전체. 실제 학습시간은 사용자가 알려준 경우만 기록한다.**  
오늘은 요청에 따라 도래 복습을 건너뛴다. review_schedule.md 일정은 바꾸지 않으며 다음 예정일은 2026-10-28이다.

## 목표

업무 문장에서 누가 행동하는지, 무엇을 하는지, 대상·기한·방법·장소가 무엇인지 구분한다. 문장이 여러 개면 각 문장의 조건을 따로 표시하고 바꾸지 않은 채 한 문장으로 요약한다.

## 개념 강의: 15~20분

문장을 읽을 때 먼저 서술어(무엇을 한다는 말)를 찾는다. 그 서술어와 연결해 질문한다.

- 누가 그 행동을 하나? → 주체
- 무슨 행동을 하나? → 행동
- 무엇을 하거나 처리하나? → 대상
- 언제까지 또는 언제 이후인가? → 시간·기한
- 어떤 수단으로, 어디에 하나? → 방법·장소

예시: “회의 담당자는 회의록을 회의 종료 후 30분 안에 공동 문서함에 올린다.”

- 행동: 올린다
- 주체: 회의 담당자
- 대상: 회의록
- 기한: 회의 종료 후 30분 안
- 장소: 공동 문서함

한 문장에 조건이 둘 이상 있거나 문장이 둘이면 각각 표시한다. 다음 문장의 조건을 앞 문장에 옮기거나, ‘후’, ‘이내’, ‘까지’ 같은 시간 표현을 빼면 뜻이 달라질 수 있다.

## 풀이 시범: 요약하기

“운영자는 백업 결과를 매일 18시까지 내부 저장소에 기록한다. 장애가 나면 복구 완료 후 1시간 안에 책임자에게 전화로 알린다.”

1) 첫 문장: 운영자 / 기록한다 / 백업 결과 / 매일 18시까지 / 내부 저장소.  
2) 둘째 문장: (운영자는) / 알린다 / 장애 상황 / 복구 완료 후 1시간 안 / 책임자에게 전화.  
3) 요약할 때 두 행동의 대상·시간·방법을 서로 섞지 않았는지 대조한다.

## 기초 연습

NCS-D002-Q001은 주체를 확인했다. 다음 Q002에서는 대상과 주체·기한·장소를 구별한다. 문제는 한 개씩 제시한다.

## 적용 연습

Q003에서 두 업무 문장을 조건을 바꾸지 않고 요약한다. 정답과 해설은 제출 전에 공개하지 않는다.

## 마무리

학습자가 “누가 무엇을, 언제, 어떤 방법으로 하는지” 자기 말로 요약한다. 답을 받은 뒤 필요한 부분만 교정하고 세션·진도를 저장한다.
