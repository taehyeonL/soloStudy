# 정보보안기사 — 2027년 필기·실기 합격 목표

상태: 미시작. 사용자 요청에 따른 잠정 학습 분류는 시스템 보안·네트워크 보안·애플리케이션 보안·정보보안 일반·정보보안 관리 및 법규다. 실기는 단답·서술·실무 상황을 연습한다. 이 목록을 2027년 공식 출제기준으로 확정하지 않는다.

2026-10-26 KCA 자격검정 공식 사이트 https://www.cq.or.kr/ 에서 최신 출제기준 원문을 확인하려 했으나 대기열로 본문/첨부 확인 실패. **2027년 적용 과목 명칭·세부 항목·실기 형식·공식 시험 일정은 검증 필요.** 비공식 요약을 확인 완료의 근거로 사용하지 않는다. 공식 자료를 받으면 적용기간·문서 제목·게시일·URL과 변경점을 기록하고 계획을 조정한다.

문제는 필기 security-written, 실기 security-practical로 분리한다. 실기는 핵심 키워드·기술적 정확성·필수 내용 누락·서술 명확성을 문제별 루브릭으로 평가한다. AI 평가는 참고용이고 불확실성을 표시한다. 객관식 점수와 합산하지 않는다. 법규 문제는 출제 시점의 공식 법령과 적용일을 확인한다.
