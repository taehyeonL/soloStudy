# 정보보안기사 — 2027년 필기·실기 합격 목표

상태: 새 집중 코스 미착수. 기존 TCP/IP·IP 관련 학습은 기초 진도로 보존하며, 아래 8주 집중 코스 완료로 간주하지 않는다. KCA 공식 시험안내에 표시된 현재 필기 과목은 시스템 보안·네트워크 보안·애플리케이션 보안·정보보안 일반·정보보안 관리 및 법규다. 실기는 단답·서술·실무 상황을 연습한다.

2026-10-28 KCA [공식 시험안내](https://www.cq.or.kr/qh_quagm01_020.do)를 확인했다. 현재 페이지는 필기 5과목(시스템 보안·네트워크 보안·애플리케이션 보안·정보보안 일반·정보보안 관리 및 법규), 과목별 20문항·4지선다·총 2시간 30분, 과목별 40점 이상 및 평균 60점 이상을 안내한다. 페이지 확인만으로 2027년 출제기준의 적용기간/세부 항목이 확정되지는 않으므로 **2027년 원문 세부 기준·실기 적용 형식·공식 일정은 계속 검증 필요**다. 공식 기준 문서의 적용기간·제목·게시일·URL을 확인한 뒤 계획을 조정한다.

## 사용자 지정 8주 우선 학습

첫 4주는 이론, 다음 4주는 문제풀이에 배정한다. 주당 14시간 중 필기 12시간, TOEIC 2시간(주말)이다. 이 기간 신규 NCS·PSAT 학습은 보류하고 기존 기록·오답·복습 일정은 보존한다. 8주 후 TOEIC 미확보 시 NCS8h·전산/보안4h·TOEIC2h, 목표 확보 시 NCS10h·전산/보안4h로 전환한다.

| 주 | 단계 | 주요 범위 |
| --- | --- | --- |
| 1 | 이론 | 시스템 보안: 계정, 접근통제, 운영체제 보안, 악성코드, 보안 운영 |
| 2 | 이론 | 네트워크 보안: TCP/IP 위협, 서비스, 방화벽, 침입탐지, 암호 프로토콜 |
| 3 | 이론 | 애플리케이션 보안: 웹 취약점, 인증·세션, DB 보안, 시큐어코딩 |
| 4 | 이론 | 정보보안 일반 및 관리·법규: 위험·정책·암호 기초·법규와 과목 간 연결 |
| 5 | 문제풀이 | 시스템·네트워크 보안 단원별 문제와 오답 보완 |
| 6 | 문제풀이 | 애플리케이션 보안·정보보안 일반 단원별 문제 |
| 7 | 문제풀이 | 관리·법규 문제와 전 범위 혼합 세트 |
| 8 | 문제풀이 | 전 과목 시간제한 모의, 오답 재풀이, 과목별 약점 분석 |

진도는 실제 학습 완료를 기준으로 하며 달력 주차만으로 자동 완료하지 않는다. 공통 개념 강의는 computer-science의 concept_id와 연결해 중복 강의를 피하되 필기 시험별 문제 성적은 security-written로 별도 관리한다.

문제는 필기 security-written, 실기 security-practical로 분리한다. 실기는 핵심 키워드·기술적 정확성·필수 내용 누락·서술 명확성을 문제별 루브릭으로 평가한다. AI 평가는 참고용이고 불확실성을 표시한다. 객관식 점수와 합산하지 않는다. 법규 문제는 출제 시점의 공식 법령과 적용일을 확인한다.
