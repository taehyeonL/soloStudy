# TOEIC — 지원자격 확보용 보조 과목

개인 목표: **700~750점**. 주 **2시간을 주말 합계 RC50문항 진단**에 사용한다. 평일 데일리 학습에서는 제외한다. 현 점수는 미확인. 기관별 자격 기준은 실제 채용공고를 확인하며 700점이 모든 기관의 지원자격을 충족한다고 단정하지 않는다. 고득점 심화보다 기본 정확성과 요구 점수 확보를 우선한다.

기본120분: 주말 RC50문항 풀이·오답 분석·취약 개념 짧은 보완. 시간 내 미완료면 실제 풀이 수를 기록한다. 실제 시험은 듣기와 읽기를 평가하므로 응시 전 실제 음원이 있는 모의고사를 확인하고 LC/RC 취약 영역에 따라 이 120분을 한시 재배분한다. 점수의 출처·날짜·LC/RC·시간 조건을 기록한다. 모의고사와 공식 성적을 구분하고 자작 소수 문항 정답률을 TOEIC 점수로 환산하지 않는다.

목표 점수 확보의 기본 근거는 사용자가 확인한 정식 성적이다. 700점 이상(확인된 지원기관 기준이 더 높으면 그 기준)일 때 정규 TOEIC 학습을 중단한다. 750점을 초과해도 확보로 인정한다. mock_scores만으로 확보 상태를 바꾸지 않는다. 재배분 기본값은 NCS 7시간 + 전산/보안 7시간 + TOEIC 0시간이다. 성적 유효성·공고상 인정 기준은 지원 때 재확인한다. 향후 재응시 필요가 확인되면 계획을 재검토한다.

ETS 공식 안내 https://www.kr.ets.org/toeic/about/listening-reading.html (2026-10-26 확인): 듣기와 읽기를 각각 평가. 문법·어휘·독해 중심은 개인 학습 배분이며 공식 시험에서 LC가 제외된다는 뜻이 아니다. 실제 음원 없는 대본 문제는 ‘LC 대본 독해 연습’으로만 기록하며 듣기 점수에 포함하지 않는다. 모든 창작 문제는 비공식 독창적 연습문제로 표시한다.
